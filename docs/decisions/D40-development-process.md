# D40 — Процес розробки

- **Статус:** ✅ прийнято · 2026-10-08 · 👤 рішення власника (2.11, 2.12, 3.1–3.10) + ⭐ захист гілки
- **Деталі:** `docs/rules/process.md`

## Рішення
- 👤 Гілка на кожен етап → PR у `master`.
- 👤 Коміт — після готової роботи (не «щодня»). Коміти й PR робить власник; AI пропонує назву за Conventional Commits і короткий підсумок зробленого.
- 👤 AI оновлює план після кожного етапу (чекбокси, «Зроблено»).
- 👤 Коли власник підтвердив кінець етапу — AI одразу дає **бриф наступного етапу**: що й навіщо, що власнику треба знати чи вирішити, ризики, як перевіримо, розмір (додано 2026-10-09; цикл — `docs/rules/process.md`).
- 👤 Складний етап ділимо на під-етапи й виконуємо по черзі — менше багів.
- 👤 Тести — змістовні, по модулях ([D30](D30-testing-and-local-env.md)).
- 👤 Якщо в плані чогось не вказано — рішення за найкращими практиками, позначене ⭐.
- ⭐ Захист `master`: злиття лише через PR із зеленим CI (M1.10).
