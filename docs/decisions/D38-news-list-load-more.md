# D38 — Список новин: «Завантажити ще» з посиланнями для пошукових систем

- **Статус:** ✅ прийнято · 2026-10-08 · 👤 рішення власника (4.9) + ⭐ реалізація
- **Етап:** M1.4.7, M1.6

## Рішення
- 👤 Кнопка «Завантажити ще» замість нумерованих сторінок.
- ⭐ Кнопка — це посилання `?page=N+1` (сервер уміє відрендерити N-ту сторінку), клієнт перехоплює клік і дописує список. Дублі (нова новина зсунула сторінки) прибираємо за id.

## Чому
Google не натискає кнопки, але переходить за посиланнями — тож старі новини теж потрапляють в індекс. Для користувача — зручно на телефоні.

## Розглянуті альтернативи
- Нескінченна прокрутка — відхилено: футер недосяжний, погано для SEO.
- Курсорна пагінація API — можна пізніше; для неглибоких сторінок offset достатній.
