# D27 — Коментарі як на YouTube

- **Статус:** ✅ прийнято · 2026-10-08 · 👤 модель «один рівень + @згадка», до тестового деплою + ⭐ реалізація (❓ OQ-3)
- **Етап:** M1.7
- **Замінює:** [P4-2, частково P4-5, P4-9](v5-engagement.md); уточнює [D12](v5-foundation.md)

## Контекст
⚠️ Власник вважав, що коментарі вже як на YouTube, але в коді — справжнє дерево до 15 рівнів (`MAX_COMMENT_THREAD_DEPTH = 15`, `CommentThreadNode` рендерить відповіді рекурсивно). Soft delete ховає всю гілку під коментарем (P4-5); API віддає все дерево одним запитом без пагінації; лайки кожного коментаря — окремим HTTP-запитом (N+1: 100 коментарів = 100 запитів і ~200 SQL).

## Рішення
- 👤 Один рівень: корені + відповіді під коренем. Відповідь на відповідь потрапляє в ту саму гілку з «@Ім'я» на початку.
- ⭐ Модель (❓ підтвердити на старті M1.7, OQ-3):
  - усі відповіді гілки мають `parentId = rootId`, `depth = 1`;
  - кому відповіли — нове поле `replyToUserId` (FK на `User`, `ON DELETE SET NULL`); «@Ім'я» рендеримо з профілю, тож перейменування користувача оновлює згадку;
  - наявні дані «сплющуємо» разовою міграцією (адресат = автор колишнього батька).
- 👤 Видалили відповідь — інші відповіді лишаються, навіть ті, що згадували її автора (як на YouTube, У14).
- ⭐ Видалення кореня ховає всю гілку — так поводиться YouTube.
- ⭐ Порції: корені — сторінками з сортуванням «Популярні» (за замовчуванням, як на YouTube) / «Нові» (❓ OQ-3); відповіді згорнуті («▼ N відповідей») і вантажаться порціями за `rootId` (індекс `[rootId, createdAt]` уже є).
- ⭐ Лайки — `likeCount` + `myReaction` разом з порцією коментарів (один запит `CommentLike where userId, commentId IN (…)`).
- 👤 Редагування свого коментаря — протягом 15 хв, з позначкою «змінено» (`editedAt` у схемі вже є).

## Наслідки
- Purge відповіді — завжди «листок» (дітей за `parentId` у неї немає) — логіка purge спрощується.
- UI без рекурсії; на сторінці — один запит на порцію коментарів.
- Документація коментарів (`CLAUDE.md`, `architecture.md`) — оновити.

## Розглянуті альтернативи
- Дерево (як зараз) — відхилено 👤.
- Reddit-стиль «[видалено]» із збереженими відповідями під видаленим коренем — відхилено: це не модель YouTube.
