# D32 — Бекапи

- **Статус:** ✅ прийнято · 2026-10-08 · 👤 рішення власника (9.4, У22) + ⭐ зберігання й перевірка
- **Етап:** M1.11 (тест), M3.5 (прод)

## Рішення
- 👤 Дамп усієї БД, крім службових журналів (`SyncRun`, `RateLimitEvent`). Football-таблиці теж потрібні: на матчі посилаються коментарі й лайки, на клуби й турніри — пости; повторний синк дав би нові id і зламав би ці зв'язки. Таблиці невеликі.
- 👤 Частота: тест — раз на тиждень, прод — щодня.
- ⭐ Дамп шифруємо (`age` або `gpg`) і зберігаємо в приватному сховищі. ⚠️ Не артефактом GitHub Actions: репозиторій публічний, а в дампі — email-и й хеші паролів.
- ⭐ `pg_dump` перед кожною міграцією на тесті й проді.
- ⭐ Прод: раз на місяць пробне відновлення в тимчасову БД — неперевірений бекап не є бекапом.
