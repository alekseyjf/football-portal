# D31 — Тестове середовище: безкоштовний хостинг, закритий доступ, без індексації

- **Статус:** ✅ прийнято · 2026-10-08 · 👤 рішення власника (1.6, 14.2, У17, У20, У21) + ⭐ деталі; хостинг — [D58](D58-test-hosting.md) (👤 2026-11-06, OQ-7)
- **Етап:** M1.11

## Контекст
Після новин і коментарів сайт має з'явитися «у світі»: тестувальники заходять, власник перевіряє на робочому середовищі. Домен ще не куплено; бюджет — безкоштовні рівні.

## Рішення
- 👤 Безкоштовний хостинг. 🔁 2026-11-06 — [D58](D58-test-hosting.md): web і admin — Vercel Hobby, API — Render Free (нативний Node без Docker; пінг `/health` з GitHub Actions не дає процесу заснути); деплой — лише після зеленого CI. Рекомендацію «API — Docker-образ на інстансі, що не засинає» не прийнято.
- 👤 Закритий доступ: HTTP Basic Auth (спільний логін / пароль) на web, admin і Swagger. ⭐ `/health` — без пароля, для моніторингу.
- 👤 Без індексації: `X-Robots-Tag: noindex, nofollow` на всіх відповідях web / admin / API + `robots.txt` `Disallow: /`.
- ⭐ API через rewrites Next: браузер ходить лише на домен web, Next проксіює `/api/v1/*` на API. Безкоштовні домени хостингів (`*.vercel.app`, `*.onrender.com` …) для браузера — різні «сайти», тож cookies `SameSite=Lax` на окремий домен API не підуть. Admin — так само, на своєму домені.
- ⭐ `APP_ENV=test` (окремо від `NODE_ENV=production`) вмикає `noindex`, Basic Auth і Swagger. 👤 2026-10-30 (бриф M1.8): індексацію web вмикає своя серверна `SITE_INDEXING` (за замовчуванням `false` — закрито; `robots.txt` і `X-Robots-Tag` з `proxy.ts` — ✅ M1.8.3, [D34](D34-seo-multilingual.md)); чи потрібен `APP_ENV` для API — у M1.11.4.
- ⭐ Окремі секрети для тесту (`JWT_SECRET`, `EMAIL_HASH_SECRET`), не з dev.
- 👤 БД — поточна Supabase; для проду — нова чиста. ⭐ ❓ Розділити dev і test (OQ-8): поточна БД стає тестовою, для локальної розробки — новий безкоштовний проєкт або локальний Postgres. 👤 2026-11-06: розділення відкладено, правила міграцій для спільної БД — одразу ([D58](D58-test-hosting.md)).
- 👤 Синк: на тесті автосинк ввімкнено, локально — вимкнено ([D36](D36-sync-operations.md)). ⭐ LIVE-cron на тесті вимкнено (квота).

## Наслідки
- Прод матиме іншу топологію — власний домен і піддомени (M3.1, OQ-9).
- ⭐ `TRUST_PROXY` перевіряємо наживо (два клієнти — різні `req.ip`), інакше ліміт логіну стане спільним для всіх користувачів.
