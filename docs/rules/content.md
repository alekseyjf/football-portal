# ⭐ Правила: редакція й контент

> Нові правила (2026-10-08) — як працюють новинні редакції. Портал публікує свої й чужі новини з посиланням на джерело ([D26](../decisions/D26-post-sources.md)); посилання **не** дає права копіювати текст. Перед відкриттям сайту — юридична перевірка (M3.4).

## Чужі новини
- Переказуємо **своїми словами**; копіювати текст чужої статті — не можна, навіть із посиланням.
- Дослівна цитата — коротка (до 2–3 речень), у лапках, з посиланням на джерело.
- Кожна новина, заснована на чужій, має джерело (одне або кілька); перше — головне.
- Факти з кількох джерел — перелічуємо всі («за даними BBC Sport і The Athletic»).

## Фото й відео
- Лише ті, на які є права: власні, ліцензовані (агентства), вільні ліцензії (Wikimedia Commons — з підписом автора й ліцензією), прес-матеріали клубів.
- Кожне фото має підпис автора / джерела (`coverImageCredit`: «Фото: Getty Images») і опис для незрячих (`alt`).
- Емблеми клубів — для ідентифікації клубу, не як ілюстрація новини (права перевіряємо в M3.4).
- Відео — вбудовуємо з платформи (YouTube), не перезавантажуємо файл.

## Заголовок, анонс, текст
- EN — обов'язкова мова; UK — бажана (без неї сайт покаже EN з позначкою) ([D23](../decisions/D23-content-languages.md)).
- Анонс — 1–2 речення, без повтору заголовка (йде в стрічку й у `meta description`).
- Заголовок і анонс — простий текст: розмітку в них (`**`, `#`) сайт покаже як є.
- Текст — Markdown (розділ нижче): підзаголовки h2–h4, списки, цитати.

## Текст у Markdown ([D25](../decisions/D25-markdown-content.md))
| Що | Як писати |
|---|---|
| Абзац | Між абзацами — **порожній рядок**: один перенос рядка нового абзацу не починає |
| Підзаголовки | `## Розділ`, `### Підрозділ`, `#### Дрібніше` (h2–h4); `#` не пишемо — h1 сторінки це заголовок новини |
| Списки | `- пункт` або `1. пункт`, кожен з нового рядка |
| Цитата | Три рядки: `> Текст цитати`, потім `>`, потім `> — Автор або джерело` (рядок з одним `>` ставить автора окремим рядком, без нього Markdown зіллє їх в один); правила цитат — «Чужі новини» |
| Посилання | `[BBC Sport](https://www.bbc.com/sport)` — повна адреса |
| Жирний, курсив | `**жирний**`, `*курсив*` |
| Зображення | `![Опис для незрячих](https://…/photo.jpg "Фото: Getty Images")` — лише `https`; ⭐ у лапках — підпис автора фото |
| Таблиця | Рядок заголовків, під ним — `---` для кожної колонки; колонки розділяє вертикальна риска (приклад нижче) |

```markdown
Арсенал обіграв Челсі в лондонському дербі.

## Голи

- 12' — Сака
- 78' — Мадуеке

> «Ми заслужили перемогу».
>
> — Головний тренер «Арсенала», пресконференція після матчу

| Команда | Удари | Володіння |
|---|---|---|
| Арсенал | 15 | 58% |
| Челсі | 9 | 42% |
```

- ⭐ Підпис фото — у лапках після адреси (title зображення): опис для незрячих і підпис лишаються разом із картинкою; рендерер (M1.5) ставить підпис під нею.
- Сирий HTML (`<div>`, `<iframe>`, `<script>`) не працює — рендерер його відкидає. Решту синтаксису Markdown (код, закреслення, виноски) у новинах не використовуємо.
- Довжина тексту — до 100 000 символів разом із розміткою.
- Покроково, з повним прикладом новини (поля, теги, посилання, `meta description`, прев'ю в соцмережах) — [`editor-guide.md`](../editor-guide.md).

## Теги
- Тег — редакційна тема (трансфери, аналітика, травми); турнір і клуб — окремі прив'язки, не теги.
- Назва тегу — EN (обов'язково) + UK; slug після створення не змінюється.

## Виправлення
- Помилку у фактах виправляємо з позначкою внизу: «Оновлено 12.10.2026: виправлено рахунок матчу». Тихо переписувати опубліковане — ні.
- Опублікований slug не змінюємо без потреби (редирект спрацює, але посилання в соцмережах уже розійшлись).
